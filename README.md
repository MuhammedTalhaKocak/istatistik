# İstatistik

A sequential, from-first-principles journey through statistics — one topic per notebook, each numbered in learning order (01 → 88).

## How This Repository Is Organized

Each folder follows the same flow: a concept is introduced with a plain-language definition, worked through with a concrete numeric example, and then verified with the corresponding Python calculation. Topics build cumulatively — later folders (hypothesis testing, ANOVA, correlation) assume the earlier ones (descriptive statistics, probability, distributions) are already understood, so the numbering reflects the actual learning path, not just a file index.

**Tech stack:** Python · NumPy · SciPy · Pandas · Statsmodels · Pingouin · Matplotlib · Seaborn

**Notebook format:** Concept explanation (Turkish) → concrete numeric example → Python verification/visualization.
